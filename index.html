GOOGLE DRIVE

Paste your Google API key once, then add any folders shared as “Anyone with the link”. Subfolders are included.

How do I get an API key?
  1. Open console.cloud.google.com and create a project.
  2. Under APIs & Services → Library, enable Google Drive API.
  3. Under Credentials, create an API key. Restrict it to the Google Drive API and to this site’s address.
  4. In Drive, share your music folder as Anyone with the link · Viewer, then paste its link above.
